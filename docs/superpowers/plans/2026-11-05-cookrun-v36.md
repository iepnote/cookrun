# 쿠킹런 v36 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

- 계획 버전: v1 (2026-11-05)

**Goal:** 쿠킹런 v35를 v36으로 올린다. 디자인 통합 규칙(크기 토큰·화면 3종)을 적용하고, 재미 요소 8가지(프로필·수준·효과음·손님 주문·주기/먹기·도감·선택 반영·깜짝 요소)와 조작 활동 4가지(달걀 깨기·수도꼭지·설거지·과일 꼬치)를 추가한다.

**Architecture:** 앱은 오프라인 단일 HTML(`index.html`, 그림 100장과 폰트가 base64로 박혀 5MB)이다. 편집이 가능하도록 `src/index.template.html`(그림 자리표시자) + `assets/`로 분리하고 `tools/build.py`로 `index.html`을 다시 만든다. 배포물은 여전히 `index.html` 하나다. 모든 게임 로직은 템플릿 안의 두 번째 `<script>`에 있고, 새 기능은 기존 패턴(`build*(w)` 빌더, `IMG[key]` 있으면 그림·없으면 이모지, `localStorage`)을 따른다.

**Tech Stack:** 순수 HTML/CSS/JS(프레임워크 없음), Web Audio, Web Speech, `localStorage`. 빌드·그림 처리는 Python 3 + Pillow. 테스트는 Node 22 `node --test` + Playwright(사전 설치, `/opt/node-tools/node_modules`).

**Spec:** `docs/superpowers/specs/2026-11-05-cookrun-v36-design.md`

## Global Constraints

- 모든 편집은 `src/index.template.html`에서 하고, 커밋 전에 반드시 `python3 tools/build.py`로 `index.html`을 재생성해 함께 커밋한다. `index.html`을 직접 고치지 않는다.
- 파일 머리말 주석의 버전은 최종 과제에서 `v36`으로 올린다. 설계 문서·계획 문서 수정 시 문서 상단 버전(v1 → v2…)을 올린다.
- 크기 토큰 값(spec §1-1): `--sz-hand:10vmin; --sz-tool:20vmin; --sz-knife:36vmin; --sz-food:30vmin; --sz-ing:16vmin; --sz-vessel:50vmin; --sz-bit:5vmin`.
- 기본 요리 11종(+꼬치)의 놀이 화면에 `IMG` 키가 있는 요소는 이모지를 쓰지 않는다. 그림이 없는 새 요소는 `IMG[key]`가 있으면 자동 교체되는 구조로 만든다.
- 놀라게 하는 소리·화면 흔들림·급작스런 등장 없음(spec §8).
- 수준 공식: `N(base)=Math.max(2,Math.round(base*LV().k))`, k는 가 0.4 / 나 0.7 / 다 1.0.
- 피드백 순서: pipbar → 단위마다 sparkle+단위 효과음 → 완료 `SND.good()` → `succeed()`.
- 테스트 실행: `NODE_PATH=/opt/node-tools/node_modules node --test tools/test/*.test.mjs` (Playwright는 `chromium.launch()` 옵션 없이 동작).
- 커밋 메시지는 한국어 요약 한 줄 + 세션 attribution 두 줄(대화의 system-reminder 참조).

```python
# tools/split.py — index.html에서 그림·폰트를 꺼내 템플릿을 만든다(최초 1회)
import re, base64, pathlib
ROOT = pathlib.Path(__file__).resolve().parents[1]
src = (ROOT / 'index.html').read_text(encoding='utf-8')
img_dir = ROOT / 'assets' / 'img'; font_dir = ROOT / 'assets' / 'font'
img_dir.mkdir(parents=True, exist_ok=True); font_dir.mkdir(parents=True, exist_ok=True)

def img(m):
    key, typ, b64 = m.group(1), m.group(2), m.group(3)
    ext = 'jpg' if typ == 'jpeg' else 'png'
    (img_dir / f'{key}.{ext}').write_bytes(base64.b64decode(b64))
    return f'{key}:"@@IMG:{key}.{ext}@@"'
out = re.sub(r'(\w+):"data:image/(png|jpeg);base64,([A-Za-z0-9+/=]+)"', img, src)

n = [0]
def font(m):
    n[0] += 1; name = f'font{n[0]}.woff2'
    (font_dir / name).write_bytes(base64.b64decode(m.group(1)))
    return f'url(@@FONT:{name}@@)'
out = re.sub(r'url\(data:font/woff2;base64,([A-Za-z0-9+/=]+)\)', font, out)

(ROOT / 'src').mkdir(exist_ok=True)
(ROOT / 'src' / 'index.template.html').write_text(out, encoding='utf-8')
print('images', len(list(img_dir.iterdir())), 'fonts', n[0], 'template bytes', len(out))
```

- [ ] **Step 2: build.py 작성**

```python
# tools/build.py — 템플릿 + assets → index.html
import re, base64, pathlib
ROOT = pathlib.Path(__file__).resolve().parents[1]
tpl = (ROOT / 'src' / 'index.template.html').read_text(encoding='utf-8')
MIME = {'png': 'image/png', 'jpg': 'image/jpeg'}
def img(m):
    name = m.group(1); ext = name.rsplit('.', 1)[1]
    data = base64.b64encode((ROOT / 'assets' / 'img' / name).read_bytes()).decode()
    return f'data:{MIME[ext]};base64,{data}'
out = re.sub(r'@@IMG:([\w.]+)@@', img, tpl)
def font(m):
    data = base64.b64encode((ROOT / 'assets' / 'font' / m.group(1)).read_bytes()).decode()
    return f'data:font/woff2;base64,{data}'
out = re.sub(r'@@FONT:([\w.]+)@@', font, out)
assert '@@' not in out, '치환되지 않은 자리표시자가 있음'
(ROOT / 'index.html').write_text(out, encoding='utf-8')
print('index.html', len(out.encode()), 'bytes')
```

```js
// tools/test/_lib.mjs
import pw from 'playwright';
import path from 'node:path'; import { fileURLToPath } from 'node:url';
const ROOT = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '../..');
export const APP = 'file://' + path.join(ROOT, 'index.html');

export async function openApp(opts = {}) {
  const browser = await pw.chromium.launch();
  const page = await browser.newPage({ viewport: { width: 1280, height: 800 } });
  const errors = [];
  page.on('console', m => { if (m.type() === 'error' || m.type() === 'assert') errors.push(m.text()); });
  page.on('pageerror', e => errors.push(String(e)));
  await page.addInitScript(() => { window.speechSynthesis = { speak(){}, cancel(){}, getVoices(){ return []; } }; });
  await page.goto(APP); await page.waitForTimeout(300);
  if (opts.level) await page.evaluate(l => { localStorage.setItem('cookrun_profiles', JSON.stringify([{ id: 't1', name: '테스트', photo: null, level: l, stamps: {}, stars: 0 }])); localStorage.setItem('cookrun_cur', 't1'); }, opts.level);
  if (opts.set) await page.evaluate(s => Object.assign(window.__T.SET, s), opts.set);
  if (opts.level) { await page.reload(); await page.waitForTimeout(300); }
  return { browser, page, errors };
}
export const screen = page => page.evaluate(() => window.__T.screen());
export async function clickNext(page, n = 1) { for (let i = 0; i < n; i++) { await page.click('#nav-next'); await page.waitForTimeout(250); } }
export async function goDish(page, name) {            // 시작 → (주문 건너뜀) → 요리 고르기 → 레시피 확인 화면까지
  await page.click('#btn-start'); await page.waitForTimeout(200);
  if (await screen(page) === 's-order') { await page.click('#order-ok'); await page.waitForTimeout(200); }
  await page.locator('.dish', { hasText: name }).first().click(); await page.waitForTimeout(300);
}
export async function pickAll(page, names) {           // 장바구니에서 재료 이름대로 고르기
  for (const nm of names) { await page.locator('.pantry', { hasText: nm }).first().click(); await page.waitForTimeout(120); }
  await page.waitForTimeout(600);
}
async function box(page, sel) { const b = await page.locator(sel).first().boundingBox(); if (!b) throw new Error('no box ' + sel); return b; }
export async function rubLR(page, sel, times, amp = 70) {
  const b = await box(page, sel); const cx = b.x + b.width / 2, cy = b.y + b.height / 2;
  await page.mouse.move(cx, cy); await page.mouse.down();
  for (let i = 0; i < times; i++) { await page.mouse.move(cx + (i % 2 ? amp : -amp), cy, { steps: 4 }); await page.waitForTimeout(20); }
  await page.mouse.up();
}
export async function circle(page, sel, turns, r = 80) {
  const b = await box(page, sel); const cx = b.x + b.width / 2, cy = b.y + b.height * 0.46;
  await page.mouse.move(cx + r, cy); await page.mouse.down();
  const steps = 24 * turns; for (let i = 1; i <= steps; i++) { const a = i / 24 * Math.PI * 2; await page.mouse.move(cx + Math.cos(a) * r, cy + Math.sin(a) * r); }
  await page.mouse.up();
}
export async function dragTo(page, fromSel, toSel) {
  const a = await box(page, fromSel), b = await box(page, toSel);
  await page.mouse.move(a.x + a.width / 2, a.y + a.height / 2); await page.mouse.down();
  await page.mouse.move(b.x + b.width / 2, b.y + b.height / 2, { steps: 12 }); await page.mouse.up(); await page.waitForTimeout(300);
}
export async function swipeDown(page, sel, px = 160) {
  const b = await box(page, sel); const cx = b.x + b.width / 2, cy = b.y + b.height * 0.3;
  await page.mouse.move(cx, cy); await page.mouse.down(); await page.mouse.move(cx, cy + px, { steps: 10 }); await page.mouse.up();
}
export async function flickUp(page, sel) {
  const b = await box(page, sel); const cx = b.x + b.width / 2, cy = b.y + b.height / 2;
  await page.mouse.move(cx, cy); await page.mouse.down(); await page.mouse.move(cx, cy - 120, { steps: 3 }); await page.mouse.up(); await page.waitForTimeout(950);
}
export async function tap(page, sel, n = 1) { for (let i = 0; i < n; i++) { await page.locator(sel).first().dispatchEvent('pointerdown', { pointerId: 1, clientX: 0, clientY: 0 }); await page.waitForTimeout(120); } }
```

```python
# tools/fix_herocut.py — 네 모서리에서 검은색 영역을 투명으로 flood fill
from PIL import Image, ImageDraw
import pathlib
p = pathlib.Path(__file__).resolve().parents[1] / 'assets' / 'img' / 'heroCut.png'
im = Image.open(p).convert('RGBA'); w, h = im.size
for xy in [(0, 0), (w - 1, 0), (0, h - 1), (w - 1, h - 1)]:
    if im.getpixel(xy)[:3] == (0, 0, 0):
        ImageDraw.floodfill(im, xy, (0, 0, 0, 0), thresh=40)
im.save(p); print('saved', im.getpixel((0, 0)))
```
